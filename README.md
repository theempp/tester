# HOUR ZERO

Local Next.js App Router / TypeScript build from `BUILD-BRIEF.md`. No deployment or paid generation was performed.

## Run

```sh
npm install
npm run dev
```

Preview: http://localhost:3001

`npm run typecheck` and `npm run build` validate the app. The scripts in `scripts/` run isolated Chrome checks and author the Blender asset; they never use the owner's browser profile.

## Content and ordering

Set `HOUR_ZERO_CHECKOUT_URL` to the actual purchase destination before building a release. Without it, the purchase link leads to the explicit “Ordering to be announced” status. No fake checkout, price, batch records, wholesale customers, or tasting notes were invented. The origin/process/variety come from the supplied packaging art. The date overprint uses the current Connecticut calendar date for this dry-run demonstration; production fulfillment must supply the actual batch roast date.

## Scene

One persistent transparent R3F Canvas carries the same Blender-authored pouch through the turn, seam opening, individual-bean pour, and viewport-sized pile. Film files are unchanged. Local Draco decoding avoids external decoder requests. The counter, video seeks, object poses, and beans derive from one scroll-progress value. The 60 ms-per-digit roll uses film-time-equivalent scroll intervals, not a wall-clock timer.

The brief's 34/22 runway notation is interpreted as 34/22 viewport lengths: 3400/2200 CSS vh of travel, plus the held viewport. This preserves the intended long four-part sequence; literal 34 CSS vh would collapse the entire story into one-third of a screen.

The held GLB front uses projected film lighting, captured from the actual browser-displayed last frame. During the turn, corrected geometry-based typography replaces the inherited clipped film print while the front is facing away. This preserves the accepted film appearance at the handoff. The editable Blender master and script live outside `public/`; the optimized GLB and static derivative ship separately.

Magic UI registry sources were fetched using the requested shadcn registry commands and preserved in `assets/source/magic-ui-registry/`. Runtime adaptations use GSAP/CSS rather than Motion. Grain, cursor, ticker, grid, rails, and purchase-link components are in `components/ui/`; the label lens and section choreography live in `components/sections.tsx`.
